# Dataset provenance

## Summary

**Every case in this repository is synthetic.** No real patient data, no
de-identified real patient data, and no restricted dataset is used, required,
downloaded, or committed here.

## `data/synthetic/benchmark_v1.json`

| | |
|---|---|
| **Origin** | Hand-authored for this project by the repository author |
| **Provenance label** | `DataProvenance.MANUAL_SYNTHETIC` (recorded on every case) |
| **Generated by** | `python scripts/generate_benchmark.py` |
| **Source of truth** | `app/benchmark/generator.py` — the JSON is a build artifact of that module |
| **Cases** | 10 (one per `CaseType`) |
| **Contains PHI** | No |
| **Redistribution** | Freely redistributable under the repository's MIT license |

The clinical content is fictional. Patient ages, sexes, conditions, laboratory
values, and medication regimens were written to be *clinically plausible* so
that the benchmark meaningfully exercises an evaluator — not to describe any
real person, and not to serve as clinical reference material.

Because the file is regenerated from `app/benchmark/generator.py`, the
generator is the authoritative artifact. Regenerating produces byte-identical
output (asserted by `tests/benchmark/test_generator.py`).

## Synthea

Synthea (a synthetic patient generator) is named in the architecture as a
possible source of realistic structured patient timelines in later phases. As
of Phase 1 it is **not** used, and no Synthea output is committed here. When it
is used, those cases will carry `DataProvenance.SYNTHEA_DERIVED`, and generated
text will still not be treated as ground truth on its own — gold-standard facts
remain a separate, deliberately authored annotation layer.

## Restricted datasets (MIMIC-IV-Note and similar)

The system is architected so that a credentialed user could point it at a
restricted dataset **locally**, on their own infrastructure, under their own
data use agreement. To be explicit about what this repository does and does not
do:

- Restricted data is **never** downloaded by this project.
- Restricted data is **never** committed to this repository.
- Restricted data is **not required** — the entire application runs on the
  committed synthetic benchmark.
- Obtaining credentials and complying with the relevant data use agreement is
  entirely the responsibility of anyone who chooses to do this.

## Intended use of this data

Evaluation and research on AI summarization behavior. Not for clinical
decision-making, not for training models intended for patient care, and not as
a source of medical information.
